# Portfolio Gaps — Devtools / DX lane

> Seeded from legacy portfolio-gaps.md. Will be overwritten by grade-jobs Phase 3 on next canonical run.

## Open gaps

- **Public open-source devtool shipped** — Cernio is itself a devtool but private. A public OSS devtool (CLI, library, framework) would be the canonical lane-anchor evidence.
- **API design fluency at popular library scale** — beyond consumer use; designing the public surface area of a developer-facing library.
- **Product-aware engineering** — Devtools interviews weight product-thinking + DX-craft. Building something developers love is the load-bearing signal.

## Confirmed strengths

- **Cernio as the meta-devtool** — a structured job-discovery DSL targeting a specific developer audience (engineers searching for engineering roles). Lane-aligned shape.
- **CLI design discipline** — Cernio's command surface (resolve / search / check / clean / import / format) demonstrates CLI-shaped thinking.
- **Tauri 2 production deployment** — Image Browser + Aurix + Tessarix all demonstrate desktop devtool shipping at production discipline.
- **Cross-language tooling** — Rust + TypeScript + Python represented across project portfolio; transferable to polyglot developer-platform engineering.

## Closure prescriptions

1. **Open-source a Cernio component as a standalone library.** The ATS provider abstraction (Greenhouse / Lever / Ashby / Workable / SmartRecruiters / Workday fetchers + retry/backoff helpers) is the most self-contained piece; would be a useful Rust crate.
2. **Apply to Anysphere / Vercel / Supabase / Linear / Replit / Posthog / GitHub.** Devtools companies value the public-OSS signal — the application material IS the GitHub portfolio.
3. **Build a small dev-productivity utility.** Even a focused CLI (timer / file-watcher / Git workflow helper) shipped as a `cargo install` crate creates the visible-OSS-devtool signal.

## Pinnacle-relevant evidence

- Vercel / Supabase / Linear / Anysphere / Replit / GitHub / Posthog / Sentry — pinnacle Devtools / DX employers.
- Most are remote-friendly, aligning with Strategy A post-exit-leverage trajectory.
