## Methodologies and Soft Skills

The portfolio's project files surface several recurring methodological patterns that span multiple domains and are themselves engineering signal.

- **Documentation-first iteration with externalised planning.** Visible in Chrona (`plans/NNN_topic.md` schema with 11 required sections per plan — Goal, Context, Rejected alternatives, Assumptions, Interfaces, Impacted areas, Incremental implementation, Testing, Risks, Exit criteria, Future considerations), Vynapse (`plans/evolutionary-trainer-modular-refactor.md` written first then executed across commits `456d9d1` and `1c01e02`), Consilium (`IMPLEMENT_NOW_*` playbooks under Header/Modules/Function-inventory/Tasks/Verify/Invariants/Tests schema), Aurix (`context/plans/vector-a*.md` + `context/references/v3-mathematics-deep-dive.md` 110KB + 10 sibling research papers ~770KB commissioned the day before the M2.0→M2.8 sprint), Tectra (README-as-design-document treating 14 milestones as spec). The pattern is consistent: write the plan before the code, capture rejected alternatives alongside the chosen path, set measurable exit criteria.

- **Iterative milestone-driven delivery with phased commits.** NeuroDrive M6 shipped across six staged commits each with its own tests — S1 plumbing, S2 plasticity, S3 homeostasis, S4 structural plasticity, S5 analytics, S6 side-by-side. Aurix Vector A shipped 21 commits across M2.0 → M2.8 in a single two-day arc plus the 2026-05-04 audit + implementation cycle. Cernio's 12-session arc moved from 0 to 14k LOC + 346 tests + 9 skills + 27 audit findings + 5-iteration rubric.

- **Test-as-evidence discipline.** Cernio's retroactive 316-test pass surfaced two silent data-loss bugs and the Workday UK-filter silent bypass immediately when build-time invariants landed. Image Browser's audit replaced 3 `unsafe` blocks with `bytemuck::cast_slice` after writing parity tests. NeuroDrive's deterministic LCG 1200-step replay test pins bitwise-identical position/velocity/heading. Nyquestro's `run_twice_identical_sequence_identical_output` pins byte-deterministic engine output across the full simulator → engine → event-stream pipeline.

- **Cross-disciplinary synthesis at the design layer.** NeuroDrive maps primary neuroscience literature (Schultz 1997 on dopamine prediction error, Turrigiano on synaptic scaling, Markram/Bi/Poo on STDP, Dohare et al. 2024 on Continual Backprop) into a Rust implementation that explicitly rejects ML-toolkit defaults (dropout → homeostasis, EWC → complementary learning systems, batchnorm → synaptic scaling, NEAT → CBP, replay buffer → hippocampal consolidation). Aurix maps 11 research papers (~17,000 lines, ~770 KB) onto the Vector A subsystem map — `v3-mathematics-deep-dive.md` → Math, `backtest-statistical-methodology.md` → Strategies + Headline, etc.

- **Diagnostic instrumentation as a first-class deliverable.** NeuroDrive's feature-gated profiling system + 10-section analytics report + 5-category crash classification + 7 automated diagnostic flags + learning-phase classifier is treated as a deliverable alongside the simulation. Image Browser's `--profiling` flag + PerfLayer + 12 named diagnostics across 17 call sites replaces a planned Python-reference validation harness with "encode the validation into the runtime; the report is the debugger".

- **Honest project-state reporting.** Across paused and dormant project files — Vynapse, Consilium, Xyntra, Tectra, Chrona, AsteroidsAI — the LifeOS source consistently reconciles README claims against code reality with severity-ranked gap inventories, ratio analyses (Tectra README-to-source 13:1; Chrona docs:source ~6:1; Xyntra test:source ~1.9:1), anti-puffing callouts ("If any external summary describes Chrona as 'a content-addressed VCS in C++', that summary is wrong"), and explicit acknowledgement of dormancy boundaries. The capacity to write down the gaps your own README hides is itself a transferable engineering signal.

- **Plain-text inspectable artefacts.** Nyquestro's JSONL flight recorder with dotted-event-name discriminated unions designed for `cat | jq` analysis. Aurix's telemetry persisting buffered events to `~/Library/Logs/com.ataca.aurix/last-session.json` consumed post-hoc by `jq` (the LpSettingsForm crash diagnosis came from reading the log, not from screenshots). NEAT genome `.dot` files in AsteroidsAI rendering directly via Graphviz. The discipline favours grep / jq / Graphviz over UI-bound observability.

- **Parallel-agent dispatch for wide-scope authoring.** Tessarix 2026-05-12 wave shipping 31 widgets via 7 Opus background agents in worktree isolation, one per lesson, each with self-contained briefs encoding existing widget library + theme tokens + schema for new widget creation — captured durably as auto-memory `project_parallel_agent_dispatch_for_wide_scope.md`. Cernio's `discover-companies` skill dispatches parallel sector agents (AI/ML, fintech, trading, systems, devtools, non-obvious sources) writing to per-territory discovery files for orchestrator import. Open Source Contributions `scout-issues` skill running parallel agents across all 9 vetted projects.
