# Engines and Runtimes

> Heavyweight execution environments with their own execution model.

| Engine | Proficiency | Evidence |
|--------|-------------|----------|
| ONNX Runtime | Comfortable | **Image Browser**: three image encoders (CLIP ViT-B/32 separate-graph, DINOv2-Base, SigLIP-2 Base 256) and two text encoders (CLIP BPE, SigLIP-2 SentencePiece) all wired through shared M2-tuned `Session` builder; CoreML disabled uniformly on macOS due to transformer-op runtime errors; CUDA target-gated on non-macOS with CPU fallback; Phase 12 dynamic `intra_threads(N/enabled_encoders)` shares the M2 P-cluster. **Open Source Contributions / tinygrad PR #16119**: 14-tokenised-line minimum LSTM operator in `tinygrad/nn/onnx.py`; passes 2 of 4 upstream ONNX-conformance LSTM tests (`test_lstm_defaults`, `test_lstm_with_initial_bias`); Silero VAD v5 parity-tested. ONNX-Runtime use across distinct projects, plus custom-operator authoring (the tinygrad LSTM PR is the depth signal beyond black-box API consumption). |
| SQLite (WAL mode) | Proficient | **Cernio**: WAL on every open; single-file local-first datastore; 5 tables, 6 idempotent migrations; companies/jobs/decisions schema with archival lifecycle; `UNIQUE` constraints as dedup; the `companies.website` and `jobs.url` constraints are dedup mechanism across all layers. **Image Browser**: writer + read-only secondary connection pattern (R2) closing perf-1777212369 22s freeze; `BEGIN IMMEDIATE` per ~32-row chunk; manual `checkpoint_passive` between encoder batches; `wal_autocheckpoint=0`; `journal_size_limit=64 MiB`; 4 idempotent ALTER-TABLE migrations + `embedding_pipeline_version` meta migration. **Aurix**: writer thread + reader pool; 60s tokio-driven `PRAGMA wal_checkpoint(TRUNCATE)`; `synchronous=NORMAL`, `foreign_keys=ON`, `temp_store=MEMORY`; idempotency keyed on domain-natural composites; TEXT-decimal big-integer encoding for uint160/uint128/int256. Three projects, three different topologies, deep schema-design + concurrency-correctness work. |
| Tauri 2 WebView | Comfortable | **Image Browser** + **Aurix** + **Tessarix**: native Rust host + system WebView; strict no-shared-memory / no-shared-fs / no-WebSocket contract between WebView and Rust process; assetProtocol for image loading at gallery scale (avoids base64-over-IPC); `tauri::ipc::Channel<StreamEvent>` for SSE-style streaming; capability-based security model. Three production-shaped apps. |
| Bevy ECS | Comfortable | **NeuroDrive**: seven Bevy plugins + `sim` coordination module; per-archetype filtering via ZST marker components leveraged as the core of post-M6 trainer-layout design; `FixedUpdate` 60 Hz simulation across four causally-ordered `SimSet` stages (`Input → Physics → Collision → Measurement`); `Update` for frame-rate-decoupled rendering; `Last` schedule for shutdown flush; disjoint-query patterns. Single project at substantial depth. |
| Ollama (local model runner) | Familiar | **Tessarix**: production model `llama3.2:3b` via Ollama at `http://localhost:11434/v1/chat/completions`; tested `llama3.2:3b`, `llama3.2:1b`, `qwen3.5:4b`, `gemma2:2b` with documented failure modes (qwen2.5:3b factor-of-4 hallucinations, Chinese-token leakage; gemma2:2b architectural symbolic-hallucination); JSON-schema mode for tiered hints; SSE streaming. **Consilium**: default Ollama roster of three model families (`llama3.2`, `qwen3.5:4b`, `gemma3:4b`); deliberate heterogeneity over three copies of one model. |
| Ethereum JSON-RPC + The Graph hosted subgraph | Comfortable | **Aurix**: read-only Ethereum JSON-RPC via Alchemy archive (chunked `eth_getLogs` + finalised-block helper) + LlamaRPC + Cloudflare + chain-official L2 RPCs; three-tier `ArchiveSource` polymorphism (subgraph → user-Alchemy → public-RPC → empty state); `parse_uint256`/`parse_int256`/`parse_uint160_word`/`parse_uint128_word`/`parse_int24_word` decoders; two's-complement sign-extension on int24; event-signature topic[0] keccak verification; 10+ decoder tests. Single project, substantial depth across 5 chains × 3 protocols. |
| Apple Accelerate AMX | Familiar | **NeuroDrive**: dual GEMM backend with SIMD fallback plus Apple Accelerate AMX path. Single use site; tied to M2 performance overhaul. |
| Coinbase Advanced Trade WebSocket | Familiar | **Nyquestro**: `level2` WebSocket client over `tokio-tungstenite`; L2-per-level updates translated to per-order virtual `SimAction` events keyed by `HashMap<(Symbol, Side, Px), OrderID>` for idempotent retraction; `SNAPSHOT_LEVEL_CAP=50` truncating 25,000+-level snapshots at wire-parse boundary; exponential reconnect backoff (250ms → 30s); status surfaced as `FeedEvent::Status` banner. Single live-feed integration. |
| LiteDB | Familiar | **Performance Profiler**: see Libraries.md — also functions as an embedded execution engine with its own WAL, checkpoint cadence, and indexing surface. |
| KaTeX | Familiar | **Tessarix**: math rendering at build time via `remark-math` → `rehype-katex`; chosen over MathJax for speed + dependency-free + server-side renderable. |
| Cargo workspace runtime | Familiar | **Vynapse**: dependency-direction enforcement via `Cargo.toml`-declared dependencies rather than convention. Subset of Rust framework knowledge. |
