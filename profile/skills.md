## Methodologies and Soft Skills

The portfolio's project files surface several recurring methodological patterns that span multiple domains and are themselves engineering signal.

- **Documentation-first iteration with externalised planning.** Visible in Chrona (`plans/NNN_topic.md` schema with 11 required sections per plan — Goal, Context, Rejected alternatives, Assumptions, Interfaces, Impacted areas, Incremental implementation, Testing, Risks, Exit criteria, Future considerations), Vynapse (`plans/evolutionary-trainer-modular-refactor.md` written first then executed across commits `456d9d1` and `1c01e02`), Consilium (`IMPLEMENT_NOW_*` playbooks under Header/Modules/Function-inventory/Tasks/Verify/Invariants/Tests schema), Aurix (`context/plans/vector-a*.md` + `context/references/v3-mathematics-deep-dive.md` 110KB + 10 sibling research papers ~770KB commissioned the day before the M2.0→M2.8 sprint), Tectra (README-as-design-document treating 14 milestones as spec). The pattern is consistent: write the plan before the code, capture rejected alternatives alongside the chosen path, set measurable exit criteria.

- **Iterative milestone-driven delivery with phased commits.** NeuroDrive M6 shipped across six staged commits each with its own tests — S1 plumbing, S2 plasticity, S3 homeostasis, S4 structural plasticity, S5 analytics, S6 side-by-side. Aurix Vector A shipped 21 commits across M2.0 → M2.8 in a single two-day arc plus the 2026-05-04 audit + implementation cycle. Cernio's 12-session arc moved from 0 to 14k LOC + 346 tests + 9 skills + 27 audit findings + 5-iteration rubric.

- **Test-as-evidence discipline.** Cernio's retroactive 316-test pass surfaced two silent data-loss bugs and the Workday UK-filter silent bypass immediately when build-time invariants landed. Image Browser's audit replaced 3 `unsafe` blocks with `bytemuck::cast_slice` after writing parity tests. NeuroDrive's deterministic LCG 1200-step replay test pins bitwise-identical position/velocity/heading. Nyquestro's `run_twice_identical_sequence_identical_output` pins byte-deterministic engine output across the full simulator → engine → event-stream pipeline.

- **Cross-disciplinary synthesis at the design layer.** NeuroDrive maps primary neuroscience literature (Schultz 1997 on dopamine prediction error, Turrigiano on synaptic scaling, Markram/Bi/Poo on STDP, Dohare et al. 2024 on Continual Backprop) into a Rust implementation that explicitly rejects ML-toolkit defaults (dropout → homeostasis, EWC → complementary learning systems, batchnorm → synaptic scaling, NEAT → CBP, replay buffer → hippocampal consolidation).
